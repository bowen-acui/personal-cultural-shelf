# 阿崔的精神地图：触达与克制视觉升级设计

日期：2026-07-13

## 1. 目标理解

这个网站不是阅读管理器，也不是豆瓣替代品。它只留下一个公开结果：阿崔读过、看过、听过什么。数据退后，封面和作品本身成为精神经验的地图。

本轮升级遵循五个个人化原则：

1. **先看见，后理解**：主页仍是散落的作品，不先出现表格、时间线或统计。
2. **信息按触碰出现**：标题、创作者和分类只在访客主动触碰作品时显现。
3. **一次只看一件**：聚焦状态隔离一件作品，周围环境退后，但不离开原陈列。
4. **短暂而可逆**：点击空白、按 Escape、切换媒介或聚焦另一件作品都能立即退出。
5. **克制胜过装饰**：材质只服务于触达和层级，不加入无意义的发光、漂浮或连续动画。

## 2. 选定方向

采用“暖玻璃聚焦层”，而不是传统详情弹窗、侧边栏或原地无限放大。

- 单击封面：封面从原位置抬起，平滑移动到视口焦点并完整显示。
- 背景：其他封面轻微降低对比度和清晰度，仍能辨认原来的精神地图。
- 信息：标题、创作者、书籍完读月份和分类位于暖纸色半透明信息层。
- 再单击另一件作品：焦点直接切换，不经过关闭再打开的空白状态。
- 单击聚焦层以外、按 Escape、切换书影音或进入目录：关闭聚焦。
- 拖拽超过 6px 时只移动封面，不触发聚焦。
- 分享选择模式中，单击继续承担“选择”语义，不打开聚焦。

## 3. 材质语言

玻璃不是独立风格，而是暖纸世界中被触摸后出现的一层空气。

- 背景遮罩：暖黑透明层，不使用纯黑。
- 玻璃底色：由纸张色混合透明白，保持整体暖度。
- 边缘：一条半透明高光边与一条内侧暗边，模拟折射。
- 阴影：一层近距离接触阴影和一层大范围环境阴影，方向统一向右下。
- 模糊：只模糊聚焦层背后的环境；封面和文字始终清晰。
- 圆角：聚焦信息层 20px，封面保持作品本身的小圆角，不把所有内容变成大卡片。

## 4. 聚焦构图

### 桌面

- 聚焦层最大宽度 820px，采用封面与信息左右错位构图。
- 书和电影封面最大高度约 68vh；音乐封面保持正方形。
- 信息不重复私人数据，只显示作品名、创作者、公开分类；书籍可显示完读月份。
- 当前媒介以一个极轻的“书 / 影 / 音”标签出现，不增加按钮。

### 移动端

- 聚焦层占用视口安全区域，上方留出品牌呼吸空间，下方避开浏览器手势区。
- 封面居中完整显示，信息层贴近封面下缘，不形成独立底部抽屉。
- 点击遮罩的可用面积保持充足，不放置多余关闭按钮；保留一个可访问的关闭按钮供明确操作。

## 5. 控制栏重构

底部胶囊包含三个语义组：

1. 陈列：散落、抖动、整理、漩涡。
2. 操作：筛选、分享。
3. 去向：目录。

组之间使用低对比度分隔线。当前陈列模式使用内凹浅层和一个小状态点，不再使用整块高饱和橙色。目录是同一胶囊中的安静链接，文案改为“目录”，不使用突兀的外链符号。

移动端保留横向滚动，但隐藏滚动条，并在左右边缘提供轻微渐隐，提示还有内容。

## 6. 字体与排版

- 中文展示标题使用系统宋体栈；英文与数字展示标题使用 Instrument Serif。
- 正文和操作使用 Inter / 苹方系统字体。
- Space Mono 只用于数量、媒介缩写和极小元数据。
- 品牌标题不再长期使用强斜体；斜体只用于英文或少量编辑性强调。
- 浏览页主标题从当前 58-150px 缩至更克制的 52-112px，并增加上方留白。
- 正文行宽控制在 28-36 个汉字，行高 1.55-1.7。
- 所有中文标题使用 `text-wrap: balance`，正文使用 `text-wrap: pretty`，避免单字孤行。

## 7. 浏览页与关于页

浏览页仍是安静的第二观看方式，不成为数据库后台：

- 搜索与筛选合并为暖玻璃工具条，使用细边、内高光和柔和模糊。
- 卡片不增加边框容器，继续让封面承担视觉主体。
- 卡片标题与元数据缩小层级差，避免每张封面都成为一个“商品卡片”。
- 顶部“浏览”改为“目录”，与陈列页用词一致。

关于页保持短篇自述：缩短行宽、增加段间距、降低大标题尺度，不增加项目说明列表。

## 8. 动效

- 聚焦进入：320ms，`cubic-bezier(.22,1,.36,1)`。
- 聚焦切换：220ms，先淡出文字再替换封面，避免闪烁。
- 遮罩：240ms 透明度和模糊渐变。
- 按压：80ms，缩放至 0.985，提供触达反馈。
- `prefers-reduced-motion` 下取消位移过渡，只保留即时显隐。
- 不增加循环动画、鼠标追踪光斑或无语义视差。

## 9. 可访问性与状态规则

- 聚焦层使用原生 `dialog`，标题关联 `aria-labelledby`，元数据关联 `aria-describedby`。
- 打开后焦点进入关闭按钮；关闭后焦点返回原封面。
- 点击 backdrop 关闭，点击内容不冒泡关闭。
- Escape 关闭当前最高层状态。
- 分享、筛选、聚焦和海报互斥。
- 所有主要触控区域至少 44 × 44px。
- 键盘 Enter 或 Space 打开聚焦；拖拽只对指针生效。

## 10. 成功标准

1. 所有书、影、音封面均可单击打开完整聚焦状态，不再需要双击。
2. 点击周围、Escape、切换媒介都会关闭；点击另一件作品直接切换。
3. 拖拽不会误触聚焦，分享选择不会打开聚焦。
4. 聚焦封面在 375px、768px、1280px 均完整可见，音乐保持 1:1。
5. 控制栏三组层级清楚，“目录”不再突兀。
6. 首页、影、音、目录、关于五类页面字体和基线统一，无明显中文孤行和横向溢出。
7. 自动测试通过，真实浏览器验证点击、关闭、键盘、移动端和控制栏状态。

## 11. 明确不做

- 不增加评分、笔记、剧情简介、播放链接或购买链接。
- 不增加新的详情页面、路由或后端。
- 不使用通用蓝紫玻璃、霓虹光晕或大面积渐变。
- 不改变 The Visible Shelf 的散落陈列逻辑，只精炼触达层和排版系统。
