# 书籍默认封面设计

## 目标与边界

对确实没有正式封面的书籍，生成一张带该书书名的默认封面。Obsidian 笔记的 `封面` 字段指向这张实际图片；网站仍只读 Obsidian，再按既有流程生成静态封面与目录数据。《王川宝典》是首个应用对象。

“没有正式封面”须由录入者确认；不能把损坏的封面路径、暂时没查到封面的正式出版物，自动当作此类作品。影、音不使用这套封面。

## 视觉

- 竖版书封面，沿用网站暖纸底色与深色文字的克制方向，不引入别的网站风格。
- 封面上唯一的文字是该书的完整书名；没有“私人藏书”、作者、网站名、徽章或水印。
- 长书名可以换行或缩小字号，但不能截断；生成后检查中文字符和小尺寸下的可读性。
- 为每本适用的书输出一张独立的 WebP；共享的是排版模板，而非所有书共用一张写着固定文字的图片。

## 数据流

1. 显式指定一条确认为无正式封面的 Obsidian 书籍笔记。
2. 根据笔记中的 `书名` 生成标题专属的默认封面，保存到 Obsidian 现有书籍封面目录。
3. 生成命令仅将该笔记的 `封面` 字段改为图片的 vault 相对路径，保留其他 frontmatter 与正文。
4. 现有同步脚本继续只读 Obsidian。若已完读笔记仍没有封面，或封面路径损坏，继续报错，不在同步时静默补图或修改笔记。

以后遇到同类书籍，对确认无正式封面的笔记运行 `node scripts/generate-default-book-cover.mjs <vault-relative-note.md>`；不批量猜测哪些笔记属于“无正式封面”。

## 验收

- 《王川宝典》的 Obsidian 笔记指向可打开的标题专属封面，且除 `封面` 外原内容不变。
- 网站生成的书籍数据包含《王川宝典》，其封面可在陈列、目录与详情中显示，书名可读。
- 其他已有书籍封面不变；空路径和损坏路径仍会被同步预检发现。
- 无后端、自动抓取、额外页面或新视觉体系。
