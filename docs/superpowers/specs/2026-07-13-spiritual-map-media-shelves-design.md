# 阿崔的精神地图：书影音陈列设计规格

## 目标

将现有个人书架调整为“阿崔的精神地图”：一个只展示阿崔读过、看过、听过什么的艺术化个人书影音档案。

网站不承担记录进度、时间、评分、评论、推荐或社交功能。作品出现在数据源中，就代表它已经进入阿崔的精神世界。

## 信息架构

- 首页名称统一为“阿崔的精神地图”。
- 顶部保留三个平行入口：书、影、音。
- 三个入口使用同一页面骨架、操作方式和视觉语言。
- 浏览页可规整查看全部作品，并按媒介和分类筛选。
- 时间线和以日期为基础的统计从主导航及产品范围中移除。

## 数据来源

| 类型 | Obsidian 目录 | 当前有效记录 | 封面形态 |
|---|---|---:|---|
| 书 | 现有閱讀書單目录 | 102 | 竖向书封 |
| 影 | `Project：存放项目的必要信息/影` | 5 | 竖向电影海报 |
| 音 | `Project：存放项目的必要信息/音` | 8 | 正方形专辑封面 |

影和音的空模板文件不导入。三类数据统一生成以下公开结构：

```json
{
  "id": "film:一一",
  "type": "film",
  "title": "一一",
  "creator": "杨德昌",
  "cover": "public/covers/...jpg",
  "categories": ["剧情"]
}
```

书籍只保留完读日期的年月；影和音不生成或展示任何日期。三类都不公开年份、评分、状态、次数、进度和私人笔记。Obsidian 始终只读。

## 视觉系统

以 The Visible Shelf 的公开可观察设计逻辑和已确认概念稿为唯一视觉方向：暖色纸张背景、细竖线、低噪音导航、真实封面阴影、散落重叠、深色悬浮控制胶囊。

三类不是三套风格，只由封面比例和陈列密度形成区别：

### 书

- 竖向书封，数量最多。
- 封面尺寸相对较小，密集重叠，形成丰富的视觉地貌。
- 保留散落、抖动、整理、漩涡、拖动、筛选和分享。

### 影

- 电影海报保持原始竖向比例。
- 海报比书封略大，间距更开，重叠更克制。
- 当前只有 5 部电影，画面依靠尺度和留白产生戏剧感，不复制书籍的密集程度。
- 操作逻辑与书保持一致。

### 音

- 专辑封面固定为正方形视觉单元。
- 8 张封面形成松散、彩色、略规整的拼贴。
- 整理模式形成正方形网格；散落模式保留轻微旋转和重叠。
- 操作逻辑与书、影保持一致。

## 作品交互

- 单击或键盘聚焦：显示名称与创作者。
- 双击或 Enter：打开简洁详情弹窗。
- 筛选：只按现有分类过滤。
- 分享：在当前媒介中选择五件作品生成方形图片。
- 书籍详情可显示完读年月；影和音不显示日期、年份、评分和内容简介。

## 响应式规则

- 桌面端保留宽阔纸面与固定底部控制胶囊。
- 移动端保留书、影、音完整导航和全部核心操作。
- 移动端通过延长垂直画布容纳作品，不把封面缩成不可辨认的小图。
- 专辑封面保持 1:1；书和电影保留各自原始长宽比。

## 数据和错误边界

- 缺少名称或封面的记录不导入。
- 空模板自动忽略。
- 封面只接受 vault 内的 JPG、JPEG、PNG、WebP 或 AVIF 文件。
- 某一媒介没有数据时显示空陈列架，不制造假作品。
- 数据构建失败不写回 Obsidian。

## 验收标准

1. 网站品牌全部改为“阿崔的精神地图”。
2. 书、影、音三个入口均加载真实数据并使用共享陈列交互。
3. 影显示 5 部电影及正确海报，音显示 8 张专辑及正确封面。
4. 书籍公开 JSON 最多包含完读年月；影和音不包含日期字段，三类都不包含年份。
5. 三类在视觉上属于同一系统，但封面比例、尺寸与密度符合本规格。
6. 桌面 1280px、平板 768px、手机 375px 的全部页面通过真实浏览器视觉检查。
7. 所有自动测试、数据路径检查、安全审查和最终视觉双审查通过。

## 明确不做

- 想看、在看、想听、追剧和进度。
- 影和音的日期、年份、时间线、年度回顾。
- 评分、评论、摘抄和私人笔记。
- 推荐、排行、社交和自动同步平台。
- 复杂精神坐标或作品关系图。
