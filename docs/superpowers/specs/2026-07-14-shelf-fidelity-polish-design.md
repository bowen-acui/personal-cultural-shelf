# 阿崔的精神地图：方案 B 定向优化规格

## 目标

在不改变“书、影、音三种陈列架”和 The Visible Shelf 散落式视觉逻辑的前提下，修复全站已发现的移动端密度、底栏可发现性、交互可访问性、页面元信息、中文排版与资源体积问题。

本轮不新增统计、时间线、关系图、推荐或后端能力，也不自动改写 Obsidian 中的分类内容。

## 视觉与交互边界

- 首页仍默认进入书籍散落陈列。
- 书、影、音继续使用同一套 DOM 陈列对象、拖拽、抖动、整理、散落、漩涡、筛选和分享逻辑。
- 详情仍为当前页面的透明浮动对象：单击封面打开，单击卡片翻转，点击透明背景或 Escape 关闭。
- 详情卡不使用玻璃材质；背面继续使用控制栏的深色和陶土色标题。
- 筛选与分享属于工具层，保留轻微玻璃质感，但减少通用弹窗感，使边框、阴影、颜色与纸面和控制栏一致。
- 移动端底栏改为固定数量、可滚动操作区、固定目录入口；目录不再依赖用户猜测横向滚动。

## 1. 交互与可访问性

### 页面切换

书、影、音在无刷新切换时同步更新 `document.title`、description、当前导航状态和 history 状态。浏览器后退/前进保持相同结果。

### 焦点路径

- 打开筛选后，焦点进入第一个分类按钮；关闭后返回筛选按钮。
- 进入分享选择模式后，焦点进入第一件可选藏品；取消或生成后返回分享按钮。
- 打开详情后，原生 dialog 保持焦点约束；关闭后返回触发封面。
- 所有布局模式按钮使用 `aria-pressed` 表示当前模式。
- 五个页面都提供跳转主内容的 skip link。

### 触控目标

桌面和移动端所有导航、操作、筛选、关闭和页脚可操作元素都达到至少 44px 的可点击区域；视觉文字可以小，但点击区域不能小。

### 错误输出

数据读取错误使用 DOM 节点和 `textContent` 生成，不再将异常字符串拼进 `innerHTML`。

## 2. 陈列密度与响应式

### 书籍

保留现有桌面散落气质，移动端提高覆盖密度，目标是让 102 本书的画布接近 3,000–3,800px，而不是约 5,400px。

### 音乐

音乐使用更高密度的方形专辑墙：桌面目标高度约 2,200–2,800px，移动端目标高度约 3,600–4,800px。专辑仍保持足够触控尺寸，并保留重叠和旋转。

### 电影

电影只有 5 部，保留当前留白和大幅海报节奏，不为了填满页面而增加无意义内容。

### 底栏

移动端底栏采用三段结构：

```text
数量 | 操作滚动区（抖动 / 筛选 / 整理 / 散落 / 漩涡 / 分享） | 目录
```

目录保持始终可见；中间操作区可横向滚动，并用轻微边缘提示表达仍可继续滑动。

## 3. 视觉精修

- 关于页面正文增加中文排版约束，避免“看过什 / 么”这类语义断裂。
- 详情卡对超长音乐标题使用紧凑字号和行距状态；短标题维持当前视觉比例。
- 详情关闭按钮降低视觉重量并贴近卡片边缘，但保留 44px 操作区域。
- 筛选和分享工具统一纸面、深色控制栏与陶土色令牌，去除突兀的通用玻璃卡片观感。
- 活跃陶土色在深色底栏中调整到满足小字号文字对比度的范围；详情标题仍可使用较大字号陶土色。

## 4. 资源与性能

- 构建阶段为封面生成适合陈列和详情的尺寸，优先使用 WebP，保留 JPEG 回退。
- HTML 使用 `srcset` 或等价尺寸选择，避免 1200px 原图被缩放到 150–220px 后直接传输。
- 首屏陈列只加载必要图片，其余继续懒加载，并提供稳定的尺寸占位，减少空白封面和布局跳动。
- 目录卡片使用离屏渲染优化，保持完整浏览，不引入分页或后端。
- Instrument Serif 与 Space Mono 改为项目本地资源，避免 Google Fonts 网络依赖；中文继续沿用系统字体栈。
- 目标：封面总资源从约 84MB 降至 20–25MB 以内；音乐页首屏资源控制在约 3MB 以内。

## 5. 发布完整度

- 添加项目 favicon。
- 添加基础 Open Graph / Twitter 图片与页面描述。
- 添加品牌化 404 页面。
- canonical 等依赖最终部署域名的字段暂不硬编码，待 GitHub Pages 域名确认后补齐。

## 6. 数据范围

- 继续保留现有 312 条公开记录：书 102、影 5、音 205。
- 评分只属于书籍，最高 5 分。
- 不自动合并音乐分类；`Mandopop`、`华语流行` 等归类保留原始 Obsidian 数据，另行确认后再处理。
- 不新增日期、笔记、摘录、ISBN、来源或私人字段。

## 7. 验证标准

- `npm test` 全部通过。
- 真实 Chrome 验证 390、768、1365px 三档。
- 五个页面均检查：默认态、悬停/焦点、筛选、分享、详情翻转、关闭、空结果和错误状态。
- 书、影、音切换后标题、description、URL 和后退/前进一致。
- 移动端无横向溢出；目录在不滑动底栏的情况下可见。
- 最长音乐标题不裁切；关于页面无孤立汉字或语义短语断裂。
- 记录图片资源体积、首屏传输量与封面加载状态，确认性能优化没有削弱散落艺术形态。

## 明确不做

- 不重写为 React 或其他框架。
- 不建立后端、数据库或自动同步。
- 不加入统计、时间线、推荐、关系图或社交功能。
- 不自动替用户重新分类音乐。
